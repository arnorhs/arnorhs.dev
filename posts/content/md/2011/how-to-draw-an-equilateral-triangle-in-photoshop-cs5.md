An [equilateral triangle](https://en.wikipedia.org/wiki/Equilateral_triangle), in case you've forgotten, is a triangle composed of sides that are all of the same length. For some reason I started thinking about those kinds of triangles the other day and wanted to create one, for use in a pattern or something very creative. I could have opted to just google for an image of one, but I wanted to draw one by hand. I started by creating a shape using the pen tool (p), but I found out quickly that it's not intuitively easy (at least if you've forgotten all your grade school math, like I have). I managed to draw one by iteratively measuring each side and dragging the corners, but that seemed hacky and thought there must be a more grade-school math way of doing it. Of course the Wikipedia entry had the formula for calculating the height of it, and that's just what I needed: [![Formula for calculating the height of an equilateral triangle](https://f.cl.ly/items/1F3c3333291N0g0p3D2I/Image%202011-08-31%20at%202.48.31%20AM.png "Formula for calculating the height of an equilateral triangle")](https://en.wikipedia.org/wiki/Equilateral_triangle) (Where the length of each side is "a". ie. any length you want.)

### Update: The easiest and best way to draw an equilateral triangle

### Drawing the equilateral triangle - the hard way

Using the information from the Wikipedia entry, this is how I drew the triangle in Photoshop: I placed a guide for the baseline of the triangle, one for the center of the triangle and two for the desired length I wanted the sides to have. ![Placing guides](https://arnorhs.dev/wp-content/uploads/2011/08/eqtri-01.png "Placing guides") The length of each side of the triangle is supposed to be 220 pixels long, so we can apply the formula in the Wikipedia article like so:

    h = (square root of 3 * 220) / 2
    
       = 190.5 (or 191, since we're using pixels)

If we want to do this often, and mathematical perfectness is not needed, we could actually also create a constant from the square root divided by 2, which is: 0.866

    h = 220 * 0.866
    
      = 190.5 (or 191)

So if we make a selection using the marquee tool (m) which is of that height and drag it so it aligns with the bottom guide, we can place the guide we'll use for the height of the triangle: ![Placing top guide using the marquee tool](https://arnorhs.dev/wp-content/uploads/2011/08/eqtri-02.png "Placing top guide using the marquee tool") Now we just need to select the pen tool (p) and click each corner of the guides: ![Using the pen tool to draw a triangle by clicking on the guide intersections](https://arnorhs.dev/wp-content/uploads/2011/08/eqtri-03.png "Using the pen tool to draw a triangle by clicking on the guide intersections") Then it should look something like this: ![completed equilateral triangle](https://arnorhs.dev/wp-content/uploads/2011/08/eqtri-04.png "completed equilateral triangle") And now we can try rotating it and we see that each side has the same length (just to make sure we did everything right) - press escape to cancel: ![making sure the height of the triangle was correct by rotating the image](https://arnorhs.dev/wp-content/uploads/2011/08/eqtri-05.png "making sure the height of the triangle was correct by rotating the image") Now we're actually done. We can either use the triangle like this, we can define a custom shape out of it so we could use it as any other shape in Photoshop -- or we could even create an interesting pattern using the triangle...

### Creating a pattern from the equilateral triangle

(Note: I'm using Photoshop CS5, but this should work in most modern versions of Photoshop (CS2, 3, 4 etc) Now you can be really clever and use this awesome creation as a base for a pattern for use in any Photoshop document by following these steps. Make the triangle black and make sure that your background is white. Rasterize the layer by right clicking on the layer (in the layers panel) and choosing "rasterize layer": ![rasterizing the layer by right clicking on it](https://arnorhs.dev/wp-content/uploads/2011/08/eqtri-06.png "rasterizing the layer by right clicking on it") Make sure that your document is tall enough for a second triangle directly below this one (using Image -> Canvas size) ![cropping the document so that is big enough for two triangles](https://arnorhs.dev/wp-content/uploads/2011/08/eqtri-07.png "cropping the document so that is big enough for two triangles") Duplicate the triangle, by picking the arrow tool (I have no idea what it's called -- maybe just the drag-stuff-around tool) and holding down the ALT key and dragging the triangle so it's top corner snaps to the guide on the baseline of the upper triangle. Then add a new guide at the baseline of the new triangle. And create a selection using the rectangle marquee tool around the second one following the guides. ![placing the second triangle so that it snaps to the guide of the bottom one](https://arnorhs.dev/wp-content/uploads/2011/08/eqtri-08.png "placing the second triangle so that it snaps to the guide of the bottom one") Crop the document around the guides, by using the crop tool (c) and pressing enter when it seems right: ![cropping the document by it's guides](https://arnorhs.dev/wp-content/uploads/2011/08/eqtri-09.png "cropping the document by it's guides") Make sure the lower layer is selected and use the offset tool (Filter -> Other -> Offset) to add a horizontal offset of 110 (half of the width of the triangle) and make sure vertical is 0 and that "wrap around" is selected below: ![using the offset tool to move the lower triangle so that it's center is exactly on the edge of the document](https://arnorhs.dev/wp-content/uploads/2011/08/eqtri-10.png "using the offset tool to move the lower triangle so that it's center is exactly on the edge of the document") Merge all layers by choosing Layer -> Flatten Image from the file menu. The only thing left is to define the pattern. Go to Edit -> Define Pattern and give it an epic name, like "equilateral triangle done right" ;) ![Defining a pattern out our triangle](https://arnorhs.dev/wp-content/uploads/2011/08/eqtri-11.png "Defining a pattern out our triangle") You're done.
